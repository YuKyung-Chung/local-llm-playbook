# 모델 크기와 양자화

**GPU 견적서를 쓰려면 이 문서가 필요합니다.** 실무 직결도가 가장 높은 문서 중 하나입니다.

## 모델 크기 감 잡기

| 크기 | 성격 | 용도 |
|---|---|---|
| 1B~3B | 아주 가벼움. 품질 낮음 | 간단한 분류, 엣지 |
| 7B~8B | 노트북/단일 GPU로 가능 | PoC, 간단한 요약 |
| 14B~32B | **사내 서비스의 현실적 주력** | RAG 챗봇, 문서 Q&A |
| 70B급 | 품질 좋음. GPU 여러 장 | 예산 되면 |
| 100B+ / MoE | 최상급 | 대형 프로젝트 |

**한국어 문서 Q&A라면 보통 14B~32B Instruct 모델**에서 시작합니다. 7B는 한국어 품질이 아쉽고, 70B는 GPU 비용이 급증합니다.

## VRAM 계산 공식

기본은 아주 단순합니다.

```
모델 가중치 크기(GB) ≈ 파라미터 수(B) × 비트수 / 8
```

| 정밀도 | 32B 모델 | 계산 |
|---|---|---|
| FP16 (16비트) | 약 64 GB | 32 × 16 / 8 |
| INT8 (8비트) | 약 32 GB | 32 × 8 / 8 |
| INT4 (4비트) | 약 16 GB | 32 × 4 / 8 |

여기에 **KV 캐시와 실행 오버헤드로 20~40%를 더** 잡아야 실제 필요량이 나옵니다.

```
실제 필요 VRAM ≈ 가중치 크기 × 1.3 ~ 1.5  (동시 사용자 적을 때)
```

예: 32B를 INT4로 → 16GB × 1.4 ≈ **22GB** → A6000(48GB) 한 장이면 여유, RTX 4090(24GB)은 아슬아슬.

## 양자화란

**고해상도 사진을 JPEG로 압축하는 것과 같습니다.**

원본 숫자가 `0.4827361...` 이었다면, 이걸 `0.48` 정도로 반올림해서 저장하는 겁니다. 용량은 확 줄고 품질은 조금 떨어집니다.

### 어느 정도까지 줄여도 되나

실무 감각은 이렇습니다.

| 정밀도 | 품질 손실 | 판단 |
|---|---|---|
| FP16/BF16 | 없음 (기준) | 메모리 되면 최선 |
| INT8 | 거의 없음 | 안전한 선택 |
| INT4 (Q4_K_M 등) | 약간 있음. 대체로 실용 수준 | **가성비 최적점** |
| INT3 이하 | 눈에 띄게 나빠짐 | 권장 안 함 |

**중요한 트레이드오프:** "7B를 FP16으로" vs "32B를 INT4로" 는 메모리가 비슷합니다.
이 경우 **대부분 32B INT4가 낫습니다.** 큰 모델을 압축한 쪽이 작은 모델 원본보다 성능이 좋은 경우가 많습니다.

### 양자화 방식 이름들

문서에서 만나게 될 이름입니다. 고르는 기준만 알면 됩니다.

- **GGUF (Q4_K_M, Q5_K_M 등):** llama.cpp / Ollama용. CPU도 가능. `Q4_K_M`이 가장 무난한 기본값
- **AWQ, GPTQ:** GPU 추론용. vLLM에서 주로 씀
- **FP8:** 최신 GPU(H100 등)에서 지원. 품질 손실이 적음

**폐쇄망 실무 팁:** Ollama로 PoC → vLLM으로 운영 전환하는 경로가 흔한데, 이때 **모델 포맷이 달라서 파일을 다시 받아야 합니다.** 반입 계획 세울 때 두 포맷 다 챙기거나, 운영 스택을 미리 확정하세요.

## 컨텍스트 길이도 VRAM을 먹습니다

같은 모델이라도 컨텍스트를 길게 잡으면 KV 캐시가 커집니다.

대략적인 감:
```
KV 캐시(GB) ≈ 동시 요청 수 × 컨텍스트 토큰 수 × 모델별 계수
```
계수는 모델마다 다르지만, **32B급에서 32K 컨텍스트 동시 10명이면 KV 캐시만 수십 GB**가 될 수 있습니다.

그래서 운영 설정에서:
- `max_model_len` 을 실제 필요한 만큼만 (예: 8K)
- 동시 처리 수 상한 설정
- 이 둘을 조이는 게 GPU를 더 사는 것보다 먼저입니다

## 모델 고를 때 체크리스트

- [ ] **라이선스가 상업적 사용과 금융권 내부 사용을 허용하는가** (Apache 2.0, MIT는 안전. Llama 라이선스는 조건 확인 필요)
- [ ] **한국어 성능이 검증되었나** (실제 사내 질문 20개로 직접 테스트)
- [ ] **양자화 버전이 공개되어 있는가**
- [ ] **VRAM이 감당되는가** (위 공식으로 계산)
- [ ] **모델 파일 전체 용량을 반입 매체에 담을 수 있는가**

## 정리

정리하면, 필요 VRAM은 대략 "파라미터 수 × 비트 / 8 × 1.4"이고, 양자화는 JPEG 압축 같은 것이며, 같은 메모리라면 작은 모델 원본보다 큰 모델 INT4가 대체로 낫습니다.
