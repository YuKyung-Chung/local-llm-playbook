# 추론 파라미터

API를 호출할 때 넘기는 옵션들입니다. 사내 챗봇 품질이 여기서 꽤 갈립니다.

## temperature

**답의 무작위성.** 0에 가까울수록 매번 같은 답, 높을수록 다양한 답.

내부적으로는 [[20-LLM은 어떻게 답을 만드나|다음 토큰 확률 분포]]를 평평하게 만들거나 뾰족하게 만듭니다.

| 값 | 성격 | 용도 |
|---|---|---|
| 0 ~ 0.2 | 거의 결정적 | **사내 규정 안내, 문서 Q&A, 코드 생성, 분류** |
| 0.5 ~ 0.7 | 균형 | 일반 대화 |
| 0.9 ~ 1.2 | 다양함 | 아이디어 브레인스토밍, 카피 작성 |

**우리 프로젝트는 거의 항상 0~0.3입니다.** 정확성이 목적이고, 같은 질문에 매번 다른 답이 나오면 감사 대응이 곤란하니까요.

## top_p (nucleus sampling)

확률 상위 몇 %까지만 후보로 삼을지. `top_p=0.9`면 확률 합이 90%가 될 때까지의 후보만 봅니다.

**temperature와 둘 중 하나만 조정하는 게 일반적입니다.** 둘 다 만지면 효과 예측이 어려워집니다. temperature를 주로 쓰고 top_p는 기본값(0.9~1.0)으로 두세요.

## top_k

후보를 상위 K개로 제한. `top_k=40` 같은 식. top_p와 비슷한 역할이라 보통 건드리지 않습니다.

## max_tokens

생성할 최대 토큰 수.

- 너무 작으면 답이 문장 중간에 뚝 끊깁니다
- 너무 크면 모델이 쓸데없이 길게 늘어놓을 수 있습니다
- **한국어는 토큰을 많이 먹으니 넉넉히** 잡으세요. 500자 답변을 원하면 800~1000 정도

## stop / stop_sequences

이 문자열이 나오면 생성을 멈춥니다. 구조화된 출력을 뽑을 때 유용합니다.

## repetition_penalty / frequency_penalty

같은 말을 반복하는 걸 억제합니다. 로컬 모델에서 "같은 문장을 무한 반복"하는 증상이 나오면 이걸 1.05~1.15 정도로 올려보세요.

## seed

같은 seed + temperature 0이면 재현 가능한 결과에 가까워집니다. **테스트와 회귀 검증에 유용합니다.**
다만 GPU 연산 특성상 100% 동일을 보장하지는 않습니다.

## 스트리밍 (stream)

`stream=true`로 두면 답이 완성될 때까지 기다리지 않고 토큰이 나오는 대로 흘려보냅니다.

**체감 속도가 완전히 달라집니다.** 전체 답변에 8초가 걸려도 첫 글자가 0.5초에 나오면 사람은 빠르다고 느낍니다.
사내 챗봇이라면 **반드시 스트리밍을 쓰세요.** [[33-실습3 프롬프트와 스트리밍]] 에서 구현합니다.

## 우리 프로젝트 권장 프리셋

### 사내 문서 Q&A (RAG)
```json
{
  "temperature": 0.1,
  "top_p": 0.9,
  "max_tokens": 1024,
  "stream": true
}
```

### 문서 요약
```json
{
  "temperature": 0.3,
  "max_tokens": 2048
}
```

### 분류 / 라우팅 (JSON 출력)
```json
{
  "temperature": 0,
  "max_tokens": 128
}
```

## 파라미터보다 훨씬 중요한 것: 시스템 프롬프트

솔직히 말하면, temperature를 0.1로 할지 0.2로 할지보다 **시스템 프롬프트 한 줄이 결과를 훨씬 많이 바꿉니다.**

사내 규정 Q&A용 시스템 프롬프트 예시입니다.

```
당신은 사내 규정 안내 도우미입니다.

규칙:
1. 아래 [참고자료]에 있는 내용만 근거로 답하세요.
2. 참고자료에 없는 내용은 절대 추측하지 말고 "제공된 자료에서 확인되지 않습니다"라고 답하세요.
3. 답변 끝에 근거가 된 문서명과 조항을 반드시 표시하세요.
4. 간결하게, 3~5문장 이내로 답하세요.
5. 법률 자문이나 최종 판단은 담당 부서에 문의하도록 안내하세요.

[참고자료]
{검색된 문서들}
```

2번과 3번이 [[10-용어사전#환각 Hallucination|환각]]을 줄이는 핵심입니다. 그래도 완전히 막지는 못하므로, 출처 표시로 사람이 검증할 수 있게 하는 게 실무적 해법입니다.

## 정리

정리하면, 사내 업무용은 temperature를 낮게(0~0.3), 스트리밍은 켜고, 나머지는 기본값을 쓰되, 진짜 승부는 시스템 프롬프트에서 난다는 것입니다.
