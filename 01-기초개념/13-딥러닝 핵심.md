# 딥러닝 핵심 개념

LLM의 조상이 딥러닝입니다. 여기도 **개념만** 잡고 넘어갑니다. 20분.

## 신경망이 하는 일

신경망은 결국 **입력 숫자를 받아 출력 숫자를 내는 아주 복잡한 함수**입니다.

공장 컨베이어 벨트를 떠올려 보세요. 원재료(입력)가 들어가서 여러 공정(층, layer)을 거치며 조금씩 가공되고, 마지막에 완제품(출력)이 나옵니다. 각 공정에는 조절 손잡이(파라미터)가 수백만 개 달려 있습니다.

학습이란 **완제품이 원하는 모양이 나올 때까지 그 손잡이들을 조금씩 돌리는 과정**입니다.

## 학습이 도는 방식

1. 데이터를 넣어서 결과를 뽑는다 (순전파, forward)
2. 정답과 얼마나 틀렸는지 잰다 (**손실, loss**)
3. 손잡이를 어느 쪽으로 돌려야 덜 틀릴지 계산한다 (**역전파, backpropagation**)
4. 조금 돌린다 (**경사하강법**. 얼마나 돌릴지가 **학습률, learning rate**)
5. 1~4를 수백만 번 반복

이게 GPU가 필요한 이유입니다. 이 계산이 엄청나게 많은 곱셈과 덧셈인데, GPU는 그걸 동시에 수만 개씩 처리하도록 만들어진 물건입니다.

## 알아둘 용어

### 에폭 (Epoch) / 배치 (Batch)
- 에폭: 전체 데이터를 한 바퀴 다 본 횟수
- 배치: 한 번에 묶어서 처리하는 데이터 묶음 크기

**추론에서도 배치는 중요합니다.** vLLM이 빠른 이유가 여러 사용자 요청을 배치로 묶어 GPU에 한 번에 태우기 때문입니다.

### GPU와 VRAM
GPU는 병렬 계산기, VRAM은 그 계산기가 쓰는 작업대입니다.
**모델이 VRAM에 다 안 올라가면** 시스템 메모리를 오가느라 10배 이상 느려지거나 아예 안 뜹니다. 서버 견적의 핵심입니다. [[42-GPU 사이징]]

### FP32 / FP16 / BF16 / INT8 / INT4
숫자를 몇 비트로 표현하느냐. 뒤로 갈수록 정밀도가 낮고 가볍습니다.
추론에서는 FP16/BF16이 기본, 메모리가 부족하면 INT8/INT4로 [[23-모델 크기와 양자화|양자화]]합니다.

### CUDA
NVIDIA GPU를 쓰기 위한 소프트웨어 층. **폐쇄망에서 버전 안 맞아서 제일 많이 고생하는 지점**입니다. CUDA, 드라이버, PyTorch 버전 조합을 미리 확정해서 반입해야 합니다. [[40-폐쇄망 반입 체크리스트]]

## 신경망 종류, 이름만

| 이름 | 잘하는 것 | 우리와의 관계 |
|---|---|---|
| CNN | 이미지 | 신분증 OCR 같은 데 씀. 직접 안 만듦 |
| RNN / LSTM | 순서 있는 데이터 | 트랜스포머에 밀려서 거의 안 씀 |
| **Transformer** | 언어, 사실상 전부 | **LLM의 뼈대. 이것만 알면 됨** |

트랜스포머는 [[22-트랜스포머와 어텐션]] 에서 따로 다룹니다.

## 우리는 학습을 안 합니다

다시 강조하면, 폐쇄망 로컬 LLM 구축의 99%는 **이미 학습된 모델을 가져다 추론만 돌리는 일**입니다.
손실 함수를 고르거나 학습률을 조정할 일은 없습니다. 파인튜닝을 하게 되더라도 LoRA 라이브러리가 다 처리합니다.

## 정리

정리하면, 딥러닝은 손잡이 수억 개짜리 함수를 데이터로 맞춰가는 과정이고, 그중 언어를 다루는 구조가 트랜스포머이며, 우리는 그 결과물을 GPU에 올려 쓰기만 하면 됩니다.
