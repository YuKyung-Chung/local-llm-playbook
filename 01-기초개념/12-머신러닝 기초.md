# 머신러닝 기초 개념

LLM만 다룰 거라면 이 문서는 **교양** 수준이면 됩니다. 다만 사내에 이미 신용평가 모델, 이상거래탐지(FDS) 같은 전통 ML이 돌고 있을 테니, 그쪽 팀과 대화할 때 필요한 만큼만 정리합니다.

## 머신러닝이란

규칙을 사람이 일일이 코딩하는 대신, **데이터를 보여주고 패턴을 스스로 찾게 하는 것**입니다.

스팸 메일 걸러내기를 생각해보세요.
- 전통 방식: "제목에 '무료'가 있으면 스팸" 같은 규칙을 사람이 수백 개 작성
- 머신러닝: 스팸 10만 통과 정상 메일 10만 통을 보여주고 알아서 구분하게 함

## 세 가지 학습 방식

1. **지도학습 (Supervised)**
   정답이 붙은 데이터로 학습. "이 대출 건은 부도, 저 건은 정상" 처럼 라벨이 있는 경우. 실무 ML의 대부분입니다.

2. **비지도학습 (Unsupervised)**
   정답 없이 비슷한 것끼리 묶기. 고객 세그먼트 나누기 같은 것.

3. **강화학습 (Reinforcement)**
   행동에 점수를 주고 점수를 높이도록 학습. LLM에서는 사람 선호도로 답변을 다듬는 RLHF에 쓰입니다.

## 꼭 알아야 할 용어 다섯 개

### 피처 (Feature)
모델에 넣는 입력 항목. 대출 심사라면 소득, 근속연수, 기존 대출 건수 같은 것.

### 학습/검증/테스트 분할
데이터를 세 덩어리로 나눕니다. 학습용으로 배우고, 검증용으로 조정하고, **테스트용은 마지막에 딱 한 번만** 씁니다.
시험 공부에 비유하면 학습=교과서, 검증=모의고사, 테스트=수능입니다. 수능 문제로 공부하면 실력을 측정할 수 없죠.

### 과적합 (Overfitting)
학습 데이터는 완벽히 맞추는데 새 데이터에는 형편없는 상태. **기출문제만 통째로 외운 학생**입니다.
증상: 학습 정확도 99%, 테스트 정확도 60%.

### 정밀도와 재현율 (Precision / Recall)
금융권에서 특히 중요합니다. 이상거래탐지로 설명하면,
- **정밀도:** 이상거래라고 잡은 것 중 진짜 이상거래 비율. 낮으면 정상 고객이 계속 차단당합니다.
- **재현율:** 실제 이상거래 중 잡아낸 비율. 낮으면 사고가 빠져나갑니다.

둘은 상충합니다. 빡세게 잡으면 재현율은 오르고 정밀도는 떨어집니다. **어느 쪽 실수가 더 아픈지**를 업무가 정해야 합니다.

### 정확도(Accuracy)의 함정
전체 중 맞춘 비율. 하지만 이상거래가 0.1%인 데이터에서 "전부 정상"이라고만 답해도 정확도 99.9%입니다. **불균형 데이터에서 정확도는 무의미합니다.**

## LLM 프로젝트와의 접점

- **평가 개념은 그대로 씁니다.** RAG 검색도 "관련 문서를 잘 찾았나"를 정밀도/재현율로 잽니다.
- **골든 데이터셋 = 테스트셋**입니다. 미리 만들어두고 건드리지 않는다는 원칙이 똑같습니다.
- **과적합 개념도 그대로**입니다. 프롬프트를 특정 예시 몇 개에만 맞춰 튜닝하면 다른 질문에서 무너집니다.

## 정리

정리하면, 머신러닝은 데이터로 패턴을 배우는 것이고, LLM 프로젝트에서 실제로 재활용되는 건 학습 알고리즘이 아니라 **"어떻게 평가할 것인가"라는 사고방식**입니다.
