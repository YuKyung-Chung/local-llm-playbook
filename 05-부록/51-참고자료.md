# 참고자료

**폐쇄망에 들어가기 전에 미리 내려받아 두세요.** [[40-폐쇄망 반입 체크리스트]]

## 이 볼트의 출발점

- [AI Engineering from Scratch](https://aiengineeringfromscratch.com) — 오픈소스 무료 커리큘럼. 20단계 523레슨. 수학부터 멀티에이전트까지 밑바닥 구현 중심. 이 볼트는 그중 폐쇄망 로컬 LLM에 필요한 부분만 추려 재구성한 것입니다. 시간이 생기면 원본의 LLM/에이전트 파트를 파보세요

내려받는 법:

```bash
wget --mirror --convert-links --page-requisites --no-parent -P ./docs https://docs.vllm.ai/
```

또는 각 GitHub 저장소를 클론하면 `docs/` 폴더가 같이 옵니다. **저장소 클론 쪽이 더 확실합니다.**

## 모델 찾기

- **Hugging Face** (https://huggingface.co/models) — 모델 저장소. 라이선스와 모델 카드를 여기서 확인
- **Ollama Library** (https://ollama.com/library) — Ollama에서 바로 쓸 수 있는 모델 목록
- **Open LLM Leaderboard** 류의 벤치마크 — 참고만 하세요. **벤치마크 점수와 우리 업무 성능은 다릅니다.** 반드시 사내 골든셋으로 직접 재세요

### 한국어 성능 확인

한국어 벤치마크(KMMLU 등)를 참고하되, **결정은 실제 사내 문서로 만든 골든셋으로** 하세요. 벤치마크 상위 모델이 우리 규정 문서 Q&A에서 더 나으리라는 보장이 없습니다.
