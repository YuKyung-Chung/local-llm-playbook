# 실습 8. MCP 클라이언트 붙이기

## 목표

MCP 서버의 도구를 **로컬 LLM이 실제로 쓰게** 만듭니다. 실습 6의 에이전트 루프 + 실습 7의 MCP 서버를 잇는 작업입니다.

## 8-1. 연결 구조

```
[로컬 LLM (Ollama)]
       ^  도구 목록 / 호출 요청
       |
[에이전트 앱]  <- 우리가 만드는 것
       |  MCP 프로토콜 (stdio)
       v
[MCP 서버들]  인사 / 문서검색 / ...
```

에이전트 앱이 하는 일은 세 가지입니다.

1. MCP 서버들에 접속해서 **도구 목록을 받아온다**
2. 그 목록을 **LLM이 이해하는 형식(OpenAI tools 스키마)으로 변환**한다
3. LLM이 도구를 부르면 **MCP 서버로 전달**하고 결과를 돌려준다

즉 **번역기**입니다.

## 8-2. 전체 코드

`C:\llm-lab\mcp_agent.py`

```python
import asyncio
import json
from contextlib import AsyncExitStack

from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

from config import get_client, CHAT_MODEL

llm = get_client()

# 연결할 MCP 서버 목록
MCP_SERVERS = {
    "hr":   {"command": "python", "args": ["mcp_hr_server.py"]},
    "docs": {"command": "python", "args": ["mcp_docs_server.py"]},
}

SYSTEM = """당신은 사내 업무 도우미입니다.

규칙:
1. 사내 제도나 규정 질문은 반드시 search_documents 도구로 확인한 뒤 답하세요.
2. 개인 인사 정보는 반드시 인사 도구로 조회하세요. 추측하지 마세요.
3. 도구 결과에 없는 내용은 만들어내지 말고 "확인되지 않습니다"라고 답하세요.
4. 문서를 근거로 답할 때는 출처를 표시하세요.
5. 한국어로 간결하게 답하세요."""


class MCPAgent:
    def __init__(self):
        self.sessions = {}        # 서버이름 -> ClientSession
        self.tool_owner = {}      # 도구이름 -> 서버이름
        self.tool_specs = []      # LLM에게 줄 스키마
        self.stack = AsyncExitStack()

    async def connect_all(self):
        for name, cfg in MCP_SERVERS.items():
            params = StdioServerParameters(command=cfg["command"], args=cfg["args"])
            read, write = await self.stack.enter_async_context(stdio_client(params))
            session = await self.stack.enter_async_context(ClientSession(read, write))
            await session.initialize()
            self.sessions[name] = session

            tools = await session.list_tools()
            for t in tools.tools:
                self.tool_owner[t.name] = name
                # MCP 스키마 -> OpenAI tools 스키마로 변환
                self.tool_specs.append({
                    "type": "function",
                    "function": {
                        "name": t.name,
                        "description": t.description or "",
                        "parameters": t.inputSchema or {"type": "object", "properties": {}},
                    },
                })
            print(f"[연결] {name}: {[t.name for t in tools.tools]}")

    async def call_tool(self, name: str, args: dict) -> str:
        server = self.tool_owner.get(name)
        if server is None:
            return f"오류: 알 수 없는 도구 {name}"
        try:
            result = await self.sessions[server].call_tool(name, args)
            return "\n".join(c.text for c in result.content if hasattr(c, "text"))
        except Exception as e:
            return f"도구 실행 오류: {e}"

    async def ask(self, question: str, max_turns: int = 6) -> str:
        messages = [
            {"role": "system", "content": SYSTEM},
            {"role": "user", "content": question},
        ]

        for _ in range(max_turns):
            resp = llm.chat.completions.create(
                model=CHAT_MODEL,
                messages=messages,
                tools=self.tool_specs,
                temperature=0,
            )
            msg = resp.choices[0].message

            if not msg.tool_calls:
                return msg.content

            messages.append(msg)

            for call in msg.tool_calls:
                args = json.loads(call.function.arguments or "{}")
                print(f"  [MCP 호출] {call.function.name}({args})")

                output = await self.call_tool(call.function.name, args)
                print(f"  [결과] {output[:120]}...")

                messages.append({
                    "role": "tool",
                    "tool_call_id": call.id,
                    "content": output,
                })

        return "처리 단계가 너무 많아 중단했습니다."

    async def close(self):
        await self.stack.aclose()


async def main():
    agent = MCPAgent()
    await agent.connect_all()
    print()

    try:
        while True:
            q = input("\n질문: ").strip()
            if q.lower() in ("quit", "exit", "종료"):
                break
            answer = await agent.ask(q)
            print(f"\n답변: {answer}")
    finally:
        await agent.close()


if __name__ == "__main__":
    asyncio.run(main())
```

## 8-4. 자주 겪는 문제

### 서버가 안 뜬다

stdio 방식은 MCP 서버를 **자식 프로세스로 실행**합니다. 서버 스크립트에 에러가 있으면 조용히 실패합니다.
먼저 `python mcp_hr_server.py` 를 단독 실행해서 에러가 없는지 확인하세요. (실행하면 입력 대기 상태로 멈춰 있는 게 정상입니다. Ctrl+C로 종료)

### 모델이 도구를 안 쓴다

- 시스템 프롬프트에 "반드시 도구를 사용하라"를 더 강하게 명시
- docstring을 더 구체적으로
- 도구 개수를 줄이기. **10개를 넘어가면 작은 모델은 급격히 나빠집니다**
- 툴 콜링 지원이 좋은 모델로 교체

### 도구가 너무 많다

서버를 여러 개 붙이면 도구가 금방 수십 개가 됩니다. 실무 대응책은 두 가지입니다.

1. **역할별로 에이전트를 나눈다.** 인사 문의 담당, 규정 문의 담당
2. **먼저 라우팅한다.** 질문을 분류해서 관련 서버만 연결

### 응답이 느리다

에이전트는 LLM을 여러 번 부릅니다. 도구를 2번 쓰면 LLM 호출이 3번입니다.
- 스트리밍은 **마지막 응답에만** 적용됩니다 (중간 단계는 사용자에게 안 보임)
- 대신 "문서를 검색하는 중입니다..." 같은 진행 표시를 UI에 넣으세요

## 8-5. stdio vs HTTP

지금까지는 stdio(자식 프로세스) 방식입니다. 사내 운영에서는 HTTP를 고려하게 됩니다.

| | stdio | HTTP (Streamable HTTP) |
|---|---|---|
| 실행 위치 | 같은 장비, 자식 프로세스 | 별도 서버 |
| 인증 | 프로세스 권한 상속 | 헤더 기반 인증 필요 |
| 확장성 | 사용자마다 프로세스 뜸 | 서버 하나로 다수 처리 |
| 운영 | 단순 | 배포/모니터링 필요 |
| 추천 | 개발, 단일 사용자 도구 | **사내 공용 서비스** |

**폐쇄망 실무 판단:** 여러 부서가 공용으로 쓸 도구(문서 검색, 인사 조회)는 HTTP 서버로 올려서 팀별로 권한을 걸고, 개인 개발 도구는 stdio로 두는 조합이 무난합니다.

HTTP 방식은 서버 코드 마지막 줄만 바꾸면 됩니다.

```python
if __name__ == "__main__":
    mcp.run(transport="streamable-http")
```

> MCP 사양은 계속 발전 중입니다. 전송 방식 이름과 옵션이 버전에 따라 다를 수 있으니, **반입할 버전의 공식 문서를 같이 챙겨 들어가세요.** 폐쇄망에서는 문서를 못 찾아 헤매는 게 진짜 시간 낭비입니다.

## 8-6. 보안 관점 정리

MCP를 도입할 때 심의에서 나올 질문들입니다. 미리 답을 준비하세요.

| 질문 | 답변 방향 |
|---|---|
| 모델이 직접 DB에 접근하나요? | 아닙니다. 모델은 도구 이름과 인자를 제안만 하고, 실행은 MCP 서버 코드가 합니다 |
| 권한 통제는 어디서? | MCP 서버의 각 도구 내부. 클라이언트를 신뢰하지 않습니다 |
| 외부 통신이 있나요? | 없습니다. stdio는 프로세스 간, HTTP는 사내망 |
| 감사 추적은? | 도구 호출 전량을 서버에서 로깅 |
| 모델이 권한 없는 걸 조회하려 하면? | 도구가 거부하고 그 시도 자체가 로그에 남습니다 |
| 프롬프트 인젝션 위험은? | 검색된 문서에 악의적 지시가 있을 수 있으므로, 쓰기 작업은 사람 승인을 거치고 1단계는 읽기 전용으로 운영합니다 |

마지막 항목이 실제로 가장 까다롭습니다. [[43-금융권 보안 규제 고려사항]] 참고.
