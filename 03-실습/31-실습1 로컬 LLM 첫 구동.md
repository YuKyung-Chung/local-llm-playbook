# 실습 1. 로컬 LLM 첫 구동

## 목표

내 PC에서 LLM을 실제로 돌려서 대화해봅니다. **여기서 "아, 이게 되는구나"를 체감하는 게 목적**입니다.

## 1-1. 모델 받기

내 하드웨어에 맞는 걸 하나 고릅니다.

```powershell
# GPU 없거나 8GB 미만 - 가볍고 빠름
ollama pull qwen3:4b

# VRAM 8GB 이상 - 권장. 한국어 무난
ollama pull qwen3:8b

# VRAM 16GB 이상 - 한국어 품질 좋음
ollama pull qwen3:14b
```

> **모델 선택 참고:** Qwen 계열은 한국어를 포함한 다국어 성능이 좋고 Apache 2.0 라이선스라 상업적 사용이 자유롭습니다. 대안으로 `gemma3`, `llama3.1` 도 있습니다. 사용 가능한 모델은 `ollama.com/library` 에서 확인하세요. 실제 사내 도입 모델은 [[23-모델 크기와 양자화]] 의 체크리스트로 별도 검증합니다.

다운로드는 몇 GB라 시간이 걸립니다. 받아지는 동안 [[20-LLM은 어떻게 답을 만드나]] 를 읽으세요.

받은 모델 확인:
```powershell
ollama list
```

## 1-2. 대화해보기

```powershell
ollama run qwen3:8b
```

프롬프트가 뜨면 아무거나 물어보세요.

```
>>> 안녕? 너는 어떤 모델이야?
>>> 파이썬으로 CSV 파일 읽는 코드 알려줘
>>> 우리 회사 취업규칙에서 육아휴직 조건 알려줘
```

**세 번째 질문의 답을 잘 보세요.** 모델은 우리 회사를 모릅니다. 그런데도 뭔가 그럴듯하게 답할 겁니다. 이게 [[10-용어사전#환각 Hallucination|환각]]입니다. **이 순간이 RAG가 왜 필요한지 이해하는 지점**입니다.

종료는 `/bye`.

## 1-3. 인터넷을 끊고 다시 해보기

이게 이번 실습의 핵심입니다.

1. Wi-Fi를 끄거나 랜선을 뽑습니다
2. 다시 `ollama run qwen3:8b`
3. 질문해봅니다

**여전히 동작합니다.** 모델 파일이 이미 로컬에 있고, 계산도 내 PC에서 하기 때문입니다.
이게 폐쇄망 로컬 LLM의 원리 전부입니다. 어렵지 않죠.

인터넷을 다시 켜세요.

## 1-4. 속도 관찰하기

```powershell
ollama run qwen3:8b --verbose
```

질문 후 아래쪽에 통계가 나옵니다.

```
total duration:       8.2s
load duration:        1.1s
prompt eval count:    24 token(s)
prompt eval duration: 0.3s
eval count:           187 token(s)
eval rate:            26.4 tokens/s     <- 이 숫자가 체감 속도
```

**`eval rate` (초당 생성 토큰 수)** 를 기억해두세요.
- 20 tokens/s 이상이면 사람이 읽는 속도와 비슷해서 쾌적합니다
- 5 tokens/s 이하면 답답합니다

같은 질문을 4b 모델과 8b 모델에 각각 던져서 **속도와 품질의 트레이드오프**를 직접 느껴보세요. 이 감각이 나중에 GPU 견적 낼 때 필요합니다.

## 1-5. 모델이 어디 저장되는지 확인

폐쇄망 반입할 때 중요합니다.

```powershell
# 기본 경로
explorer $env:USERPROFILE\.ollama\models
```

여기 있는 파일들이 실제 모델 가중치입니다. **이 폴더를 통째로 옮기면 다른 PC에서도 인터넷 없이 씁니다.** 반입 전략의 기본입니다.

## 체크포인트

- [ ] 모델이 내 PC에서 응답한다
- [ ] 인터넷을 끊어도 동작한다
- [ ] 회사 내부 정보를 물으면 지어낸다는 걸 확인했다
- [ ] `eval rate` 숫자를 확인했다
- [ ] 모델 파일 위치를 안다
