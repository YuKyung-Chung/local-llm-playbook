# 실습 0. 환경 준비

## 목표

내 PC에 LLM 실습 환경을 만듭니다. **여기는 인터넷 되는 개발 PC에서 합니다.** 폐쇄망 반입은 나중에 [[40-폐쇄망 반입 체크리스트]] 에서 다룹니다.

소요 시간: 30분 ~ 1시간 (다운로드 시간 제외)

## 0-1. 하드웨어 확인

| 조건 | 가능한 실습 |
|---|---|
| GPU 없음, RAM 16GB | 3B~4B 모델. 느리지만 전 과정 가능 |
| GPU VRAM 8GB | 7~8B 모델 (양자화). 쾌적 |
| GPU VRAM 16GB+ | 14B까지. 아주 쾌적 |

GPU가 없어도 **모든 실습을 완주할 수 있습니다.** 모델만 작은 걸 쓰면 됩니다.

내 GPU 확인 (PowerShell):
```powershell
nvidia-smi
```
출력이 안 나오면 NVIDIA GPU가 없거나 드라이버 미설치입니다. 없어도 진행하세요.

## 0-2. Python 설치

Python 3.11 또는 3.12를 권장합니다. 3.13은 일부 라이브러리가 아직 안 붙는 경우가 있습니다.

```powershell
python --version
```

없으면 [python.org](https://www.python.org/downloads/) 에서 설치. 설치 시 **"Add Python to PATH" 반드시 체크**.

## 0-3. 작업 폴더와 가상환경

```powershell
mkdir C:\llm-lab
cd C:\llm-lab
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

> PowerShell에서 실행 정책 오류가 나면:
> `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`

프롬프트 앞에 `(.venv)` 가 붙으면 성공입니다.

**왜 가상환경을 쓰나:** 프로젝트마다 라이브러리 버전이 다릅니다. 전역에 깔면 서로 충돌합니다. 그리고 나중에 폐쇄망에 반입할 때 **이 가상환경에 깔린 것만 정확히 챙기면 되므로** 목록 관리가 쉬워집니다.

## 0-4. Ollama 설치

로컬 LLM을 가장 쉽게 돌리는 도구입니다.

[ollama.com/download](https://ollama.com/download) 에서 Windows 설치 파일을 받아 설치합니다.

설치 후 확인:
```powershell
ollama --version
```

Ollama는 설치되면 백그라운드 서비스로 `http://localhost:11434` 에서 돕니다.

> **왜 Ollama부터 하나:** 실제 사내 운영은 vLLM으로 가게 될 가능성이 높습니다. 하지만 vLLM은 리눅스 + GPU 전제라 학습용으로는 진입장벽이 큽니다. Ollama로 개념을 다 익히고, API 규격(OpenAI 호환)이 같으므로 나중에 서버 주소만 바꾸면 vLLM으로 갈아탈 수 있습니다. [[41-서빙 스택 선택]]

## 0-5. 파이썬 패키지 설치

```powershell
pip install --upgrade pip
pip install openai chromadb pypdf python-docx rich
```

각각 뭔지:

| 패키지 | 용도 |
|---|---|
| `openai` | LLM 호출용 클라이언트. **OpenAI 서비스를 쓰는 게 아니라**, 로컬 서버가 OpenAI와 같은 API 규격을 제공해서 이 라이브러리로 부르는 것 |
| `chromadb` | 벡터 DB. 파일 기반이라 별도 서버 불필요 |
| `pypdf`, `python-docx` | 사내 문서(PDF, Word) 읽기 |
| `rich` | 터미널 출력 예쁘게 (선택) |

에이전트/MCP 실습 때 추가로 설치합니다. 지금은 여기까지.

## 0-6. 설치 확인

```powershell
python -c "import openai, chromadb; print('OK')"
ollama list
```

`OK` 가 찍히고 ollama 명령이 에러 없이 돌면 준비 완료입니다.
(모델은 아직 없으니 `ollama list` 결과가 비어 있는 게 정상)
