# 이 볼트를 읽는 법

## 전제

당신은 개발은 할 줄 알지만 AI/ML은 처음입니다. 그리고 시간이 없습니다.
그래서 이 볼트는 **"원리를 완벽히 이해한다"가 아니라 "구축을 완주한다"**를 목표로 합니다.

## 세 가지 종류의 문서

1. **읽기 문서** (01, 02 폴더)
   한 번 훑고 넘어가세요. 다 이해 못 해도 됩니다. 나중에 실습하다 막히면 그때 다시 옵니다.

2. **실습 문서** (03 폴더)
   여기가 본편입니다. 반드시 직접 타이핑하면서 진행하세요. 복사 붙여넣기만 하면 남는 게 없습니다.

3. **운영 문서** (04 폴더)
   실제 사내 구축 착수할 때 체크리스트로 씁니다.

## 시간 배분 권장

| 구간 | 시간 | 비고 |
|---|---|---|
| 00 + 01 + 02 읽기 | 3~4시간 | 하루 |
| 실습 0~3 | 4~6시간 | 로컬 LLM 띄우고 API로 부르기까지 |
| 실습 4~5 (RAG) | 6~8시간 | 실무에서 가장 많이 쓰는 구간 |
| 실습 6~8 (에이전트/MCP) | 8~10시간 | |
| 실습 9 (통합) | 4~6시간 | 사내 데모 가능한 결과물 |

주말 이틀 + 평일 저녁 2주 정도면 완주 가능합니다.
