# 폐쇄망 로컬 LLM 플레이북

금융권 IT 개발자가 **폐쇄망(인터넷 차단 환경) 안에 로컬 LLM을 구축**하기 위해 필요한 개념과 실습을 정리한 옵시디언 볼트입니다.

AI/ML을 한 번도 안 해본 상태에서 시작해도 따라올 수 있도록 썼습니다.

## 이 볼트의 방침

- 수학, 전통 머신러닝, 딥러닝은 **실무에서 대화가 통할 만큼만** 개념 위주로 짧게
- LLM, RAG, 에이전트, MCP는 **직접 손으로 만들어 보면서** 이해하도록 단계별 실습으로
- 모든 실습은 **인터넷 없이도 돌아가는 구성**을 전제로 합니다 (외부 API 호출 없음)

## 읽는 순서

1. [[01-내 과제 정의]] 로 목표부터 못 박기
2. [[02-30분 전체 지도]] 로 큰 그림 훑기 (**이 문서 하나만 읽어도 회의에서 말은 통합니다**)
3. [[10-용어사전]] 은 옆에 띄워두고 수시로 검색
4. `02-LLM원리` 폴더를 순서대로 (읽기만, 1~2시간)
5. `03-실습` 폴더를 순서대로 (손으로, 여기가 본편)
6. `04-폐쇄망운영` 폴더는 실제 구축에 착수할 때

일정은 [[03-8주 학습 로드맵]] 참고. 급하면 3~4주로 압축 가능합니다.

## 만들면서 알게 될 것

- LLM은 다음 단어를 확률로 찍는 기계다. 그래서 지어낸다
- 사내 지식을 넣는 방법은 파인튜닝이 아니라 거의 항상 RAG다
- 에이전트는 while 루프다. 실제 실행은 모델이 아니라 내 코드가 한다
- 금융권 프로젝트의 승패는 "잘 맞추냐"가 아니라 **"틀릴 때 틀린다고 말하고 통제가 되느냐"** 에서 갈린다
